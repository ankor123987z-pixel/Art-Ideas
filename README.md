# Арт-рулетка

Арт-рулетка — приложение для Android, которое собирает промпты для генерации изображений в ChatGPT, Grok, Midjourney и Шедевруме.

## Что умеет

- **Рулетка** подбирает сцену и художественный стиль.
- **Три подачи** собирают три промпта для одной сцены в разных стилях.
- Можно выбрать одну из **600 сцен** или написать свою.
- Промпты можно собирать и копировать офлайн.

## Скачать и установить

1. Откройте **Releases** на странице проекта и выберите последний выпуск.
2. В разделе **Assets** скачайте файл `.apk`.
3. Откройте скачанный файл на телефоне и установите приложение.

Минимальная версия — Android 8.0.
